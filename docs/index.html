Calcul des trois métriques EDI, étape par étape, avec les vraies valeurs MovieLens 100k pour Borda (k=10, θ=4.0).
ΔE — Équité entre groupes▼
1
Pour chaque groupe, calculer la satisfaction moyenne sur les k films recommandés R.
utility_F = Σ_{u∈G_F} Σ_{i∈R} w(u,i) / (|G_F| × k) utility_M = Σ_{u∈G_M} Σ_{i∈R} w(u,i) / (|G_M| × k)
2
Exemple réel (Borda, k=10) : utility_F ≈ 0.90 · utility_M ≈ 1.32
ΔE = |utility_F − utility_M| = |0.90 − 1.32| = 0.4249
ΔE = 0.4249 → les hommes retirent ~47% plus de satisfaction. Cible : ΔE ≈ 0. Notre méthode atteint ΔE=0.3511 (k=10).
ILD — Diversité intra-liste▼
1
Chaque film i → vecteur v_i ∈ ℝ^{943} : coordonnée j = note du j-ème utilisateur (0 si non noté).
2
Pour chaque paire (i,j) du top-k, calculer la dissimilarité cosinus :
dist(i,j) = 1 − (v_i · v_j) / (‖v_i‖ × ‖v_j‖)
3
k=10 → C(10,2) = 45 paires. ILD = moyenne des dissimilarités.
ILD(R) = 2/(k·(k−1)) × Σ_{i≠j ∈ R} dist(i,j)
Borda k=10 : ILD=0.354. Notre méthode : ILD=0.448 (+27%). Average Score donne ILD=1.0 mais recommande des films obscurs → inclusion quasi-nulle.
inclusion_g — Représentation du groupe g▼
1
Pour u ∈ g : compter les films du top-k notés ≥ θ = 4.0 par u.
inclusion_g(R) = (1/|G_g|) × Σ_{u∈G_g} |{i ∈ R : w(u,i) ≥ θ}| / k
2
Cibles de proportionnalité : inclusion_F ≥ α_F = 0.29 · inclusion_M ≥ α_M = 0.71
3
Notes entières → θ=3.5 ≡ θ=4.0 (sélectionnent toutes deux notes 4 et 5). Seul θ ≤ 3.0 inclurait les 3.
Pour k=20, notre méthode : inc_F=0.269 (>Borda 0.247) et inc_M=0.348 (>Borda 0.339) — seule configuration où Ours domine tout.

Ce que nous avons appris

Aucune méthode classique ne satisfait les 3 critères EDI simultanément

L'Average Score produit une équité parfaite (ΔE≈0.007) mais une inclusion quasi-nulle. Borda et Condorcet améliorent l'inclusion mais maintiennent un grand écart d'équité (ΔE≈0.42–0.49). Le Fair Re-rank améliore fortement l'équité (ΔE≈0.15–0.24) mais au prix d'une inclusion réduite.

Notre méthode domine sur 3/4 critères pour k=20 — avec le meilleur équilibre global

Coarsenisation : 943 → 272 super-nœuds (−71.2%), ratio F/M rééquilibré 29→37%. Vs Fair Re-rank : ILD=0.465 (+9%), inc_F=0.269 (+4%), inc_M=0.348 (+12%) — seule méthode offrant un équilibre entre équité, diversité et inclusion. ΔE=0.347 reste le seul critère où Fair Re-rank est meilleur (0.240).

Robustesse : l'algorithme est insensible aux tolérances ε

Les paramètres ε_E ∈ [0.05, 0.30] et ε_D ∈ [0.01, 0.12] produisent des résultats identiques. La contrainte opérationnelle est max_merges : c'est le nombre maximal de fusions qui contrôle la compression. Les résultats sont donc stables et reproductibles sans calibration fine des ε.

Observation : équivalence des seuils θ sur MovieLens

Notes entières (1–5) → θ=3.5 et θ=4.0 sélectionnent tous deux les notes ≥ 4, donnant des résultats identiques. Pour différencier ces configurations, il faudrait θ ≤ 3.0.
